<h3>About Me</h3>

<p>
I'm a Cloud &amp; DevOps engineer with <strong>6+ years of experience</strong> working on production systems. My work is mostly about finding what slows a project down — in the application, the infrastructure, or the development process — and improving it.
</p>

<p>
I focus on making systems <strong>faster, easier to operate, and less expensive to run and develop</strong>.
</p>

<ul>
  <li>⚡ Improve application and infrastructure performance, scalability, and resource usage</li>
  <li>💰 Reduce cloud costs and development costs by removing waste and simplifying workflows</li>
  <li>🚀 Improve CI/CD, build, test, deployment, and developer workflows to shorten delivery time</li>
  <li>📊 Build monitoring and observability systems that make production issues easier to detect and understand</li>
  <li>🔥 Handle production incidents, troubleshoot failures, perform root-cause analysis, and implement long-term fixes</li>
  <li>☁️ Work across private cloud and public cloud environments: <strong>AWS, Azure, and Google Cloud Platform</strong></li>
</ul>
